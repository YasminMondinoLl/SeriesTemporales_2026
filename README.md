# Series Temporales

Este repositorio contiene Notebooks en python para el estudio de series temporales.

Todos los datasets utilizados en las notebooks son de tipo hidrológico y se encuentran incluídos en este repositorio.

## Contenidos
1) Uso de pandas para la exploración de datasets en formato excel
2) Descomposición de series temporales
3) Análisis de correlación y autocorrelación
4) Métodos simples de pronóstico
5) Aplicación de transformaciones simples en series temporales

## Librerias requeridas
`numpy`
`pandas`
`scikit-learn`
`matplotlib`
`seaborn`
